# Estruturas de configuracao privada

Estes exemplos preservam apenas a estrutura dos configs rastreados nos componentes; nao sao configuracao de execucao. Valores reais e credenciais devem ser obtidos do catalogo privado e do schema/documentacao do componente. SET_PRIVATE_VALUE e numerais zero sao marcadores que exigem preenchimento; nao iniciar servicos com estes exemplos. O indice COMPONENTS.json relaciona namespaces de historia e origens relativas.
